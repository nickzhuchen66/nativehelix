# Capability Routing

Route extracted mechanisms to the 15 stable domains in `04_Capabilities/`:

1. system architecture
2. context
3. workflow
4. harness
5. evaluation
6. human–AI collaboration
7. grounding and evidence
8. memory and knowledge
9. loop engineering
10. operational control
11. agent product architecture
12. domain adaptation
13. multi-agent coordination
14. bounded self-improvement
15. reference architecture and SDK

Keep project facts, project-specific mappings, and promotion evidence in a user-approved project output directory. Do not mix them into the reusable Core by default.

If a mechanism spans domains, choose one owner domain and record dependencies rather than duplicating the full content.
