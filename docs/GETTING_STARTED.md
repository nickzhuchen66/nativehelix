# Getting Started

## Choose your entry point

- Designing an AI-native product or system: start with `design-ai-native-architecture`.
- Turning a goal into a bounded multi-stage process: start with `design-agent-workflow`.
- Reviewing an existing agent harness: start with `review-agent-harness`.
- Extracting reusable practices from a source project: start with `ingest-project-capabilities`.
- Looking for a contract or checklist rather than a full Skill: browse `04_Capabilities/INDEX.md`.

## First-use sequence

1. Define the user outcome and final artifact.
2. Select one Skill or a small set of Capability assets.
3. Read the selected `SKILL.md` completely, including only the referenced resources needed for the task.
4. Check [Public dependencies](PUBLIC_DEPENDENCIES.md) before running an optional script.
5. Apply the Skill inside your project and keep its output in your project's own authority structure.
6. Record what was observed, what was inferred, and what remains unvalidated.

## Recommended first exercise

Open `examples/weekly-project-update-agent/`. Compare its product brief, architecture boundary, and workflow. Then invoke `design-agent-workflow` on the same fictional problem and compare the output with the example.

## Maturity warning

NativeHelix assets are reusable design material, not universal guarantees. Validate permissions, tools, state, recovery, security, and product value in the environment where you intend to use them.
