# Agent Product Architecture

## 核心问题

Agent 在产品中承担什么用户价值、以何种自治程度工作，以及用户如何理解、监督和接管。

## 范围

- product outcome、artifact identity、consumption path 与 distribution boundary
- Copilot、Assistant、Agent、Autonomous System
- intent、task、approval、progress、result、failure UX
- visible workflow 与后台自治
- PROPOSE / CONFIRM / AUTO
- trust、explanation、human takeover

## Public Core evidence scope

The [Outcome–Artifact Definition Gate](contracts/outcome_artifact_definition_gate.md) is included as a candidate product capability derived from one recorded failure case. It has not yet been validated across structurally different public products.

## 当前缺口

缺用户研究、交互状态、可用性指标、Outcome–Artifact Definition Gate 的第二项目 forward test 和第二类 Agent 产品案例。Public Core 不携带私有项目成熟度证据。
