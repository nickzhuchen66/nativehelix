# Product Brief

- **User:** a project lead preparing a weekly sponsor update.
- **Problem:** relevant status is scattered across an approved set of project notes.
- **Outcome:** a concise, reviewable draft that identifies progress, risks, decisions needed, and missing information.
- **Artifact:** one private Markdown draft plus a list of cited source notes.
- **Consumption:** the project lead reviews and edits the draft before any communication.
- **Acceptance:** every statement is traceable to an approved note or labeled as an inference; missing information is explicit; nothing is sent automatically.
- **Non-goals:** performance evaluation, unrestricted search, source modification, stakeholder contact, or publication.
