# Security Policy

NativeHelix v0.1 is a documentation and Skill toolkit, not a security product.

Do not include secrets, credentials, private repository content, personal data, production data, or authenticated session material in issues, examples, Skill assets, or pull requests.

If you find a vulnerability or disclosure risk, do not open a public issue containing sensitive material. Use [GitHub private vulnerability reporting](https://github.com/nickzhuchen66/nativehelix/security/advisories/new) so the repository maintainer can review the report privately.

NativeHelix provides design guidance and checklists, but adopters remain responsible for threat modeling, access control, sandboxing, secret management, legal review, and runtime validation in their own environments.
