# Workflow

1. **Confirm scope** — the product owner supplies the approved note set and output location.
2. **Inventory inputs** — record each readable note and any missing input.
3. **Extract observations** — separate directly observed status from contributor claims.
4. **Draft sections** — prepare progress, risks, decisions, and gaps.
5. **Grounding check** — verify every material statement against an input or label it as inference.
6. **Human review** — return the private draft to the project lead.
7. **Stop** — no communication or publication action exists in this workflow.

Any request to contact stakeholders or publish the update changes the effect boundary and requires a new human decision.
