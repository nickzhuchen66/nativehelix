# Public Core Boundary

NativeHelix Public Core is a curated distribution, not a mirror of its private working repository.

## Included

- reusable Skill packages and their declared local resources;
- generic Capability definitions, contracts, patterns, checklists, and templates;
- public operating and authority guidance;
- public reference architecture;
- synthetic examples and adoption documentation.

## Excluded

- source snapshots and private research ingestion;
- private project profiles and project adapters;
- management registers and product/architecture control planes;
- handoff boards, review records, workflow failure history, and release evidence;
- project-specific datasets, business facts, identities, absolute paths, credentials, and private evidence;
- maturity claims that depend on excluded private evidence.

The private working repository may evolve faster than this public distribution. Public releases should contain explicit versions and change notes rather than automatically mirroring private state.
